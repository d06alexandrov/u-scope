# Source Types

U-Scope reads data through a common reader interface, so different kinds of inputs can be added, configured, and assigned to channels the same way. Two source types are currently available:

- **[Simulated Source](./simulated-source.html)** - a waveform generator for testing and demos.
- **[Serial Port Source](./serial-source.html)** - reads raw bytes from a serial device.

See [Source Configuration](../user-guide/source-configuration.html) for how to add a source from the UI, and [Channel Assignment](../user-guide/channel-assignment.html) for mapping a source's variables to display channels.
